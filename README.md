# Fibonacci Series in Python

## Overview
This project contains a beginner-friendly Python program to generate the Fibonacci series for a specified number of terms.

## How It Works
- Takes the number of terms as input from the user.
- Checks whether the number of terms is positive.
- Generates the Fibonacci series using a `for` loop.
- Prints the series on the screen.

## Example Output
```text
Enter the number of terms: 7
Fibonacci series:
0 1 1 2 3 5 8
```

## How to Run
1. Make sure Python is installed on your computer.
2. Download `fibonacci.py` from this repository.
3. Open a terminal in the folder containing the file.
4. Run the command:

```bash
python fibonacci.py
```

## Learning Objective
To understand loops, variables, user input, and how to generate a mathematical sequence in Python.
